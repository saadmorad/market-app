# ماركت القرية 🛒

متجر بسيط لماركت صغير: العميل يطلب (قطاعي أو جملة) والطلب يوصلك على واتساب، ولوحة تحكم بكلمة سر تتحكم منها في كل حاجة.

## الملفات
- `server.js` : السيرفر (Node.js + Express)
- `public/` : صفحة المتجر (`index.html`) ولوحة التحكم (`admin.html`)
- `default-store.json` : المنتجات التجريبية اللي بتظهر أول مرة بس
- `package.json` و `railway.json` : إعدادات التشغيل

---

## أولًا: رفع المشروع على GitHub

1. ادخل على github.com وسجّل دخول.
2. اضغط **New repository**، اكتب الاسم `village-market`، واختار **Private**، واضغط **Create repository**.
3. اضغط على رابط **uploading an existing file**.
4. فك ضغط الملف `market-app.zip` على جهازك، وبعدين **اسحب كل محتويات المجلد** (ملف `server.js` ومجلد `public` وباقي الملفات) وسيبها في صفحة GitHub.
   - لازم `server.js` يكون في أول المشروع، مش جوه مجلد تاني.
5. اضغط **Commit changes**.

## ثانيًا: ربطه بريلواي

1. ادخل على railway.com وسجّل دخول بحساب GitHub.
2. **New Project** ← **Deploy from GitHub repo** ← اختار `village-market`.
   (لو طلب صلاحية الوصول للمستودع، وافق عليها.)
3. افتح الخدمة اللي اتعملت، وادخل على **Variables** وضيف:
   - `ADMIN_PASSWORD` = كلمة سر قوية (6 حروف على الأقل). **دي كلمة سر لوحة التحكم، ما تقولهاش لحد.**
   - `DATA_DIR` = `/data`
4. **مهم جدًا:** ضيف **Volume** للخدمة (من زر **+ New** أو بالضغط يمين على الخدمة ← **Add Volume**)، واكتب مكان التركيب (Mount path): `/data`.
   من غيره كل المنتجات والصور والتعديلات **هتضيع** مع كل تحديث للمشروع.
5. من **Settings ← Networking** اضغط **Generate Domain** عشان تاخد رابط للموقع.
6. استنى لحد ما الـ Deployment يخلص. وفي الـ Logs لازم تشوف: `الماركت شغال على البورت`.

> أسماء الأزرار في ريلواي ممكن تختلف شوية مع الوقت، بس الخطوات هي هي.

## ثالثًا: أول استخدام

1. افتح `رابط-الموقع/admin` وادخل بكلمة السر.
2. **أول حاجة غيّر رقم الواتساب** (بالصيغة الدولية بدون +، مثال: `201012345678`)، وإلا الطلبات هتروح لرقم تجريبي.
3. عدّل اسم الماركت والقرى وأسعار التوصيل والمنتجات، وارفع الصور، واختار الألوان.
4. اضغط **حفظ التعديلات**.
5. انشر رابط الموقع الأساسي للعملاء (من غير `/admin`). العملاء مش بيشوفوا لوحة التحكم ولا يقدروا يدخلوها من غير كلمة السر.

## ملاحظات
- **الطلبات** بتوصلك على واتساب. وسجل "طلباتي" محفوظ على موبايل العميل نفسه.
- **نسخة احتياطية:** من لوحة التحكم اضغط "تنزيل نسخة احتياطية" من وقت للتاني.
- **لو نسيت كلمة السر:** غيّرها من Variables في ريلواي، وهيتعمل تحديث تلقائي.
- **تحديث الشكل أو الكود:** عدّل الملفات على GitHub وريلواي هيحدّث الموقع لوحده. بيانات المتجر في الـ Volume مش بتتأثر.
- **تجربة على جهازك (اختياري):** محتاج Node.js، وبعدين:
  ```
  npm install
  ADMIN_PASSWORD=123456 npm start
  ```
  وافتح `http://localhost:3000`
